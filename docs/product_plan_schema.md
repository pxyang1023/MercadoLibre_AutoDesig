# product_plan.json 字段说明

本文档说明 `plans/NB001_product_plan.json` 中各字段的用途，方便后续 Python 图片合成脚本、ComfyUI 调用脚本和 n8n 自动化流程读取。

## 顶层字段

- `product_id`：产品唯一编号，用于关联 CSV 输入、输出目录、日志和自动化任务状态。
- `product_name`：产品名称，用于生成文案、提示词和最终图片中的商品描述。
- `category`：产品类目，例如 `beverage`。后续可用于选择不同的模板、构图风格和提示词策略。
- `language`：目标文案语言。当前样例为 `es`，表示西班牙语。
- `market`：目标市场。当前样例为 `LatAm`，表示拉美市场。
- `capacity`：产品规格或容量，例如 `1L`。可用于容量卖点图和详情页文案。
- `input_image`：原始产品图路径。Python 合成脚本会读取该图片作为主体商品图。
- `output_folder`：该产品最终图片的输出目录。脚本应将 7 张成品图保存到此目录。
- `brand_style`：品牌视觉风格配置，用于统一颜色、语气和整体设计方向。
- `images`：图片计划数组，定义每一张输出图的内容、布局、文案和 ComfyUI 提示词。

## brand_style 字段

- `main_colors`：主视觉颜色列表。模板合成脚本可用这些颜色生成背景、标题、标签、按钮或装饰元素。
- `tone`：整体风格描述，例如清爽、夏季、干净、商业化。AI 文案和提示词规划可参考该字段保持风格一致。

## images 数组字段

每个 `images` 数组元素代表一张要生成的电商图片。

- `index`：图片顺序，从 1 到 7。用于排序和批量处理。
- `type`：图片类型，例如主图、卖点图、风味图、成分图、生活方式图、容量图和总结图。
- `filename`：输出文件名，应与项目配置中的命名规则保持一致。
- `title`：该图片的主标题。主白底图可为空。
- `subtitle`：该图片的副标题，用于补充主标题卖点。
- `bullets`：要展示在图片中的短卖点列表。Python 合成脚本可将其渲染为图标加文字、标签或分点说明。
- `layout`：建议使用的版式名称。合成脚本可根据该字段选择不同模板。
- `comfy_prompt`：发送给 ComfyUI 的英文提示词，用于生成背景、场景、食材、氛围或其他辅助素材。

## 处理建议

后续脚本可以按以下顺序使用该文件：

1. 读取顶层产品信息，确认输入图片和输出目录。
2. 根据 `brand_style` 设置统一视觉风格。
3. 遍历 `images` 数组，为每张图生成或读取所需素材。
4. 使用 `layout` 选择模板，将 `title`、`subtitle`、`bullets` 和产品图合成到画布。
5. 按 `filename` 保存最终 PNG 文件到 `output_folder`。
